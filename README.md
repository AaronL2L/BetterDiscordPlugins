# BetterDiscordPlugins

[BetterDiscord](https://betterdiscord.app) plugins by **AaronL2L**. Every plugin is in English and French, and follows Discord's language.

| Plugin | What it does |
|---|---|
| [EqualizeVolumes](EqualizeVolumes) | Right-click a user → "Equalize everyone's volume": one level for the whole voice channel, with an optional auto mode for newcomers. |
| [MaskedWords](MaskedWords) | Hides messages that contain words you choose, like a Discord spoiler: click to reveal. Named lists with optional durations, and right-click a text selection to hide it. |
| [MediaVault](MediaVault) | Find the media, links and files shared in any conversation: a gallery grouped by month, full-screen preview, search and member filter. |
| [BetterSidebar](BetterSidebar) | Sort and pin your servers, or leave several at once, from a button built into the server list. |
| [FriendsSortAssistant](FriendsSortAssistant) | Helps you clean up your friends list by suggesting inactive contacts, recent ones, or those with no shared servers. |
| [MessageScheduler](MessageScheduler) | Schedule messages and set reminders on existing messages. |
| [DeleteAllMessages](DeleteAllMessages) | Delete your messages in batches, with optional filters and a local backup. |
| [BetterAdmin](BetterAdmin) | Admin dashboard to manage your servers in bulk: events, security, channels, roles, backups and studio. |

## Install

1. Open the plugin's folder above and click its `.plugin.js` file.
2. Click **Download raw file** (the download icon at the top right of the file).
3. In Discord, open **User Settings → Plugins → Open Plugins Folder** and drop the file there.
4. Turn the plugin on in the list.

## Disclaimer

Some plugins act on your account for you (deleting or scheduling messages, bulk actions on servers). Discord's Terms of Service forbid automating user accounts, so use them at your own risk.
