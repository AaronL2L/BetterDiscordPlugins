# MaskedWords

Hides messages that contain words you choose, like a Discord spoiler: click one to show it.

## How to use

- **From a message:** select text, right-click it and choose **Hide selection**. Pick a list, or **Customize…** to set the list and the duration.
- **From the settings:** create named lists and add words separated by commas.

## Lists

Each list can:
- hide the **whole message** or **only the word**;
- last **always**, **24 hours**, **7 days**, **30 days** or a custom duration;
- be turned on or off at any time.

## Options

- **Blur images and videos** in hidden messages.
- **Hide in notifications:** desktop notifications show the list name instead of the message.

Only you see the difference: nothing is sent to Discord.
